# کوچه‌گرد

راهنمای فارسی اقامتگاه‌های مستقل یزد و تفت؛ با نام و عکس قابل‌پیگیری، تقویم شمسی و پیوند مستقیم به میزبان.

دموی زنده: https://mohammadkh2000.github.io/koochegard/

این پروژه برای چالش VibeFarsi ساخته شده است. VibeFarsi کد کامپوننت‌ها را داخل پروژه قرار می‌دهد؛ برای همین فایل‌های آن در `components/` و `lib/` نگه‌داری می‌شوند و به‌عنوان پکیج زمان‌اجرا در `package.json` دیده نمی‌شوند.

## کامپوننت‌های VibeFarsi در رابط

- فرم جست‌وجو: `Combobox`، `DateRangePicker` با تقویم شمسی و کنترل تعداد مهمان
- فهرست اقامتگاه: `SegmentedControl`، `Card`، `Badge` و `Carousel`
- جزئیات و راهنمای مسیر: `Sheet`، `Stepper` و `Toast`
- جلوه‌های فارسی: پس‌زمینه‌ی `Girih` و انیمیشن `Reveal`
- دکمه‌ها و کارت‌های صفحه‌ی درباره: `Button` و `Card`

چیدمان، هویت بصری کوچه‌گرد و محتوای اقامتگاه‌ها مخصوص همین پروژه است؛ اجزای تعاملی از رجیستری VibeFarsi می‌آیند و بر اساس طراحی صفحه ترکیب شده‌اند.

## شفافیت محتوا

چهار اقامتگاه با پیوند به منبع رسمی معرفی شده‌اند. منبع عکس‌ها در [`public/images/CREDITS.md`](public/images/CREDITS.md) آمده است. کارت‌های تجربه‌ی جمعی داده‌ی نمایشی‌اند؛ این نسخه ثبت‌نام یا رزرو واقعی انجام نمی‌دهد.

## اجرای محلی

```sh
npm ci
npm run dev
```

برای ساخت خروجی استاتیک:

```sh
npm run build
```

خروجی در `dist/` قرار می‌گیرد. گردش‌کار GitHub Actions آن را برای GitHub Pages منتشر می‌کند و مسیر پایه‌ی پروژه را خودکار تنظیم می‌کند.
